# DateRangePicker

**`<DateRangePicker>`** combines two DateFields and a RangeCalendar popover to allow users to enter or select a date and time range.

In forms use the **`<DateRangePickerField>`** component (see [Forms > Fields > DateRangePickerField](/docs/forms-fields-dateRangepickerfield--docs)).
